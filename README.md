# Testing the performance of polygenic scores for multiple traits to explain cerebral palsy risk in two independent cohorts

Repository for scripts used in stastical analyses to determine the ability of polygenic scores for cerebral palsy (CP) and seven related traits to distinguish CP status in two independent cohorts (Australian and MyCode cohorts), as well as in the Australian cohort stratified by monogenic diagnosis
